The challenge

  • Android & iOS duplicate networking, auth, cache, offline logic
  • Repeated boilerplate slows every feature
  • UI differs — infrastructure problems do not
  • Harder maintenance and onboarding

What is KmpSDK?

  • Shared Kotlin Multiplatform library
  • Headless — infrastructure only; you own all UI
  • Networking, auth, logging, optional offline sync, MVI contracts
  • Published on Maven Central — open source on GitHub

What it is NOT

  • Not a finished app or UI kit
  • Not no-code — teams still build screens & rules
  • Not a company product unless your org adopts it
  • Not Android-only — one module, two platforms

Architecture

  • Host app — UI, ViewModels, navigation
  • KmpSDK — core, data, domain, presentation
  • Platform — Android & iOS drivers
  • Flow: Maven → init → modules → your UI

Key capabilities

  • Authentication & token refresh
  • Configurable offline / HTTP cache
  • Multi-environment (dev / staging / prod)
  • Telemetry, remote config, cert pinning

Business value

  • Faster delivery — shared mobile infrastructure
  • Lower duplication — one KMP vs two native stacks
  • Consistent auth, errors, sync patterns
  • Documented paths for different app needs
  • Apache 2.0 — no vendor lock-in

Who benefits
